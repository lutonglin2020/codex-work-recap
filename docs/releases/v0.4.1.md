# v0.4.1 · 开源与界面更新

Codex Work Recap 按 GPL-3.0-only 发布。它把本机多个 Codex 主会话中的具体工作进展，整理成简短回顾，显示在 Windows 顶部胶囊中。

- 原生小窗使用更清晰的正文、留白和细边缘，显示最新／上次回顾及原生成时间。历史回顾不冒充新消息。
- 聊天内视图增加清楚的暂停／恢复操作和更新状态；进入更新或错误状态时保留可用回顾，新旧数据格式均有验证。
- 同步此前本地版本的工作内容规则：学习、分析、排查、方案讨论和交付都可进入回顾；重复内容继续保持安静。
- 补齐许可证、安装说明与贡献指南；安装包包含完整 GPLv3 文本。
- 附三张竖版图文与发布文案，所有画面使用场景示意或合成测试数据。

## 使用条件

Windows、Python 3.11+、已通过 ChatGPT 登录的 Codex，以及可以调用 `gpt-6.1-sol / medium` 的账号和额度。生成摘要使用在线模型；查看缓存不调用模型。暂不支持直接 API Key 登录。

安装步骤见 [README](../../README.md)。这是独立社区项目，与 OpenAI 无隶属关系。
