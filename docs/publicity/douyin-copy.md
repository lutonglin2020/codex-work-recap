## 标题

Codex 聊天开多了，我做了个工作回顾小工具

## 正文

Codex 聊天一多，代码、排查、学习内容就散在不同地方。忙了一阵，再回头看，有时还得逐个翻聊天，才能找到具体推进了什么。

我做了一个「Codex 工作回顾助手」。它读取本机已保存的 Codex 主会话，把具体进展整理成几句话，放在屏幕顶部的小胶囊里。悬停或点击就能看，查看已有回顾不会再次调用模型。

现在按 GPL-3.0 开源了。适合 Windows 用户，需 Python 3.11+、用 ChatGPT 登录 Codex，以及能调用 gpt-6.1-sol 的账号和模型额度。生成摘要会用到在线模型。

项目地址：
https://github.com/lutonglin2020/codex-work-recap

安装和数据说明都在 README。欢迎试用，也欢迎反馈实际遇到的问题。
