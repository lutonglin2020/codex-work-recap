# 原生小窗

默认界面是屏幕顶部的深色胶囊，由独立 Windows 进程绘制。它不是 Codex 内嵌面板，不修改宿主窗口或安装包。

## 展示行为

- 平时收成 120 × 22 逻辑像素的小条；悬停或点击可展开缓存摘要。
- 有值得展示的新摘要时，按模型给出的停顿建议等待用户休息或返回。自动展开至少间隔 20 分钟，同一份摘要不反复弹出。
- 悬停时保持展开，移出约 2 秒收回；未被悬停的自动展示保留约 15～25 秒阅读时间。
- 没有新内容、正在整理或更新失败时，保留上一条有效回顾供悬停查看，跨期或重启后仍可恢复。新摘要生成后替换；只有没有任何有效历史时才显示按文字宽度适配的小提示。
- 保留的旧回顾不自动弹出、不显示新内容标记，不改原始生成时间或已读状态。
- 全局常驻，不随 Codex 最小化而消失。首次放在当前显示器，之后跟随小窗所在显示器；全屏应用仅抑制自动展开。
- 右键菜单提供暂停、恢复和退出；窗口显示、更新和置顶不抢输入焦点。

## 排版与动画

摘要默认宽 560 逻辑像素，Microsoft YaHei UI 正文字号 14，行距 23，左右留白 28、上下留白 16，段间距 8。使用深炭色背景、细灰边、柔和阴影和灰白正文，没有统计或详情列表。

展开的有效回顾顶部有字号 11 的来源行，与正文留出 22 逻辑像素的位置：按 `retained` 显示“最新回顾”或“上次回顾”，时间取 `display.json.summary.generated_at` 并统一显示为北京时间；缺失或无效的时间直接省略。无历史摘要的状态提示不显示来源行，宽度仍随文字适配。收起时仅尚未展示的新回顾显示暖色小点，已展示或保留的历史回顾不显示点。

GDI+ 采用灰度抗锯齿和物理像素对齐，测量与绘制共享换行结果。窗口高度按正文计算，不通过截断正文控制长度。

展开约 300ms、收回约 200ms。文字在展开后段淡入，收回前先淡出，字号不随动画缩放。`frame_clock.py` 等待 Windows 合成时钟并合并帧消息，由 GUI 线程绘制；动画期间不读文件、不调用模型。实际流畅度受屏幕、系统合成和机器负载影响，不承诺固定帧率。

## 进程与通信

入口为 `recap.widget.run()`，实际界面在 `recap/island_widget.py`。通过 Python 标准库 `ctypes` 调用 Win32 和 GDI+，不依赖浏览器或 Tk。

小窗每 2 秒读取后台原子写入的 `display.json`：

```text
summary: {id, overview, generated_at, period_label, display_after_idle_seconds, retained} | null
state, paused, message
```

悬停、点击和动画只使用本地缓存。暂停、恢复通过本地文件 IPC 发往后台，不监听端口。`widget.lock` 保证单实例，`widget.stop` 请求退出；`island-presentation.json` 保存展示去重状态，不代替摘要的来源覆盖记录。

窗口使用 `TOPMOST`、`TOOLWINDOW`、`NOACTIVATE` 样式，每秒检查一次置顶状态，仅在丢失时恢复。只操作自身窗口，不设置其他应用焦点，也不注入 Codex。

不同 DPI、多屏、全屏应用及 Windows 会话恢复仍应在目标电脑实测；单元测试不能代替这些环境中的交互验证。

## 隔离预览

在 Windows 源码目录运行：

```powershell
python -X utf8 tests/render_native_preview.py --output evidence/native-ui --scale 2
```

这会用 `tests/` 内的合成正文生成收起、新回顾、历史回顾、空状态和暂停状态的透明 PNG，包含阴影，默认按 200% DPI 输出。输出附有合成数据说明，适合界面检查和宣传演示；不读取真实聊天、缓存或后台服务，也不显示窗口。`test_island_render.py` 在 100%、150%、175%、200% DPI 检查完整正文排版和历史回顾无新内容点。
