---
name: work-recap
description: 查看或更新本机 Codex 跨会话的工作回顾，或暂停、恢复自动回顾。用于了解最近、今天或上一个工作日做了什么；不用于修改原项目或派发任务。
---

用户已选择灵动岛式顶端收纳胶囊。平时收成小条，鼠标悬停可展开几句总结，新摘要在合适的休息或返回时机自动展示，不打开网页或文件面板，不冒充原生内嵌。用户主动查看回顾时优先调用本插件的 `get_recap`；该工具只读缓存，可在 MCP Apps 面板展示。
只有用户明确要求立即更新回顾时才调用 `refresh_recap`。它异步触发轻量模型，返回后可读缓存查看状态，不反复刷新生成。

摘要按工作内容聚合，原会话只是来源。保留计划、实现、自动验证和真实验证之间的区别，建议不代表已执行。
用户要求暂停或恢复时，调用 `set_recap_paused`。不要因为展示给模型就标记用户已读；用户在界面确认或明确要求后才调用 `mark_recap_seen`。

如果当前聊天尚未加载新装 MCP 工具，可在已安装插件目录运行 `python -m recap --status` 查看缓存；用户希望展开查看时运行 `python -m recap --show`，只显示缓存而不刷新模型。不要自行改用浏览器或文件面板。默认运行不监听端口。
插件数据来自本机当前用户可访问的 Codex 会话。不得声称包含远程或 ChatGPT 云端会话。模型额度不足时保留旧回顾并告知状态，不自动换用其他模型或外部 API。
